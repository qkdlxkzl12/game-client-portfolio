# Texas Bingo

포커 족보와 5×5 빙고를 결합한 턴제 보드게임입니다.  
각 빙고 라인을 하나의 Poker Hand로 판정하고, 상대보다 높은 족보를 완성하여 승점을 획득합니다.

본 폴더에는 포커 족보 판정, 플레이어 간 라인 비교, Mission Card 조건 및 CSV 기반 플레이 데이터 처리 코드를 정리했습니다.

## 개발 개요

- 장르: 턴제 전략 보드게임
- 개발 환경: Unity, C#
- 담당 분야: 핵심 규칙 구현, 족보 판정, 승점 계산, 플레이 데이터 처리
- 데이터 관리: ScriptableObject, CSV

## 주요 구현

### 1. Poker Hand 분석 및 판정

각 빙고 라인에 배치된 카드를 분석하여 완성 가능한 Poker Hand를 판정하는 구조를 구현했습니다.

- 카드의 Rank와 Suit별 개수 기록
- 중복 Rank와 Suit 종류 분석
- Ace를 High와 Low로 사용하는 Straight 예외 처리
- One Pair부터 Royal Flush까지 족보별 성립 가능성 판정
- 이미 성립할 수 없게 된 족보를 후보에서 제외하여 반복 판정 범위 축소

`HandAnalysis`가 카드 구성과 파생 정보를 관리하고, `PokerHandEvaluator`가 족보별 판정 규칙을 담당하도록 역할을 분리했습니다.

### 2. 빙고 라인 비교 및 승점 계산

5×5 보드의 가로 5줄, 세로 5줄, 대각선 2줄을 각각 비교하여 플레이어별 승패를 판정했습니다.

- 각 라인의 Poker Hand와 Kicker 계산
- 동일한 족보일 경우 Kicker를 순서대로 비교
- 완전히 동일한 결과에 대한 공동 승리 처리
- 라인별 승리 여부와 동일 족보 존재 여부 기록
- 전체 보드에서 가장 높은 족보 표시
- 일반 대전과 Score Mode에 따른 별도 점수 계산

족보 판정 결과를 `HandResult`로 표현하여 Rank와 Kicker 비교 규칙을 하나의 값으로 관리했습니다.

### 3. Mission Card 조건 데이터

Mission Card의 다양한 달성 조건을 데이터로 설정할 수 있도록 구성했습니다.

- 특정 가로·세로·대각선 또는 Line 그룹 지정
- 승리, 패배, 결과 무관 조건 구분
- 특정 족보와 동일·이상·이하 조건 표현
- 여러 족보의 합계와 개별 달성 횟수 설정
- Mission 달성 시 추가 점수 반영

`Flags` 기반 위치 정보와 조건별 enum을 사용하여 Mission 규칙을 코드 수정 없이 데이터 조합으로 표현할 수 있도록 설계했습니다.

### 4. CSV 기반 플레이 데이터 구성

게임 진행에 필요한 카드 순서와 상대 플레이 정보를 CSV에서 읽어 런타임 데이터로 변환했습니다.

- 게임 ID별 카드 등장 순서 구성
- Event Card에 따라 추가로 공개되는 카드 데이터 처리
- 일반 대전과 Score Mode 데이터 구분
- 상대 플레이어의 5×5 카드 배치와 Mission 정보 파싱
- 파싱된 데이터를 읽기 전용 컬렉션으로 관리

반복 테스트와 단계별 게임 구성이 가능하도록 카드 순서와 상대 행동을 외부 데이터로 분리했습니다.

## 폴더 구성

- `Evaluator`
  - `HandAnalysis.cs`: 카드 구성과 족보 가능성 분석
  - `PokerHandEvaluator.cs`: 족보별 성립 조건 판정
  - `BingoEvaluator.cs`: 플레이어별 라인 비교와 점수 계산
- `MissionCard`
  - Mission 조건과 결과 데이터 구조
  - Mission Card ScriptableObject
- `PlayDataCsvReader.cs`
  - CSV 기반 카드 순서 및 상대 플레이 데이터 파싱
